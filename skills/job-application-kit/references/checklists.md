# Checklists before delivery

Run the relevant list. Fix every failure. Then hand over.

## Resume or CV

Layout
- [ ] Single column, no layout tables, no text boxes, no icons, no skill bars
- [ ] Nothing in headers or footers
- [ ] One font family, 10.5 to 11 pt body, name 15 to 18 pt, black text
- [ ] Page size right for the market (Letter for US/CA, A4 elsewhere)
- [ ] Length right for the market and seniority; page two at least half full or cut
- [ ] Standard section names
- [ ] Reverse chronological everywhere
- [ ] Dates in one format, right-aligned, "Present" or "heute" for current
- [ ] No bullet runs past the date column; no two-word orphan lines
- [ ] Links plain, black, working, no "https://www."
- [ ] Photo, DOB, address, nationality present or absent according to the market

Content
- [ ] Contact line has city, country, email, phone, and a permit line if it helps
- [ ] Summary only if mid-level or above, three lines, positioning not personality
- [ ] Skills grouped, ordered by the posting, only interview-safe items, CEFR for languages
- [ ] Every bullet starts with a strong verb, no "responsible for", no pronouns, no full stop
- [ ] More than half the bullets carry a number or concrete scope
- [ ] Domain context in every role
- [ ] Most relevant bullets at the top of each role
- [ ] Posting's vocabulary used where true; nothing added that is not true
- [ ] Old or irrelevant roles condensed
- [ ] No objective, no "references on request", no hobbies unless relevant, no Microsoft Office
- [ ] Tense consistent within each role
- [ ] Spelling and grammar checked, company and product names spelled as they spell them
- [ ] Every `[confirm]` placeholder listed for the user

File
- [ ] PDF text extracts (run scripts/check_pdf.py)
- [ ] Page count matches the intent
- [ ] File under 1 MB, named Firstname_Lastname_Resume.pdf or the market's convention
- [ ] .docx kept for future edits

## Cover letter or Anschreiben

- [ ] One page, 200 to 400 words
- [ ] Named recipient if findable; correct spelling; correct company legal name
- [ ] Job title as in the posting; reference number included
- [ ] Opening sentence is specific to this company; no stock opener
- [ ] Two or three proofs with results, mapped to must-haves; not a resume rerun
- [ ] One concrete company-specific fact
- [ ] Obvious question (gap, switch, relocation, visa, language) answered in one or two sentences
- [ ] Salary expectation and start date included if the posting asked
- [ ] Plain close; no begging; sign-off matches the market
- [ ] Passed human-voice.md: no not-X-but-Y, no em dashes, no triads, no closer line, no inflated words, no bold, no bullets
- [ ] Read aloud; every sentence could only go to this company
- [ ] Same header and font as the resume
- [ ] DACH: DIN 5008 layout, date, subject line, "Mit freundlichen Grüßen", Anlagen line

## Application packet (DACH)

- [ ] Anschreiben, Lebenslauf, Zeugnisse in the right order
- [ ] All Zeugnisse present or their absence explained in the letter
- [ ] One merged PDF under the portal limit, or separate correctly named PDFs
- [ ] Scans straight and readable
- [ ] Foreign degree shown with equivalent; translations attached where needed

## Form fields in the portal

- [ ] Work authorisation answered correctly
- [ ] Location and willingness to relocate answered as the person actually intends
- [ ] Salary field: a number, gross annual, in the local currency
- [ ] Notice period or earliest start date filled
- [ ] Language level matches the CV
- [ ] "How did you hear about us": referral named if there is one
- [ ] Only the roles the person actually wants at this company (not five at once)

## Before sending anything

- [ ] User has seen the final text in chat and approved it
- [ ] User has the verify list: names, numbers, dates, reference number
- [ ] Tracker row added or updated
